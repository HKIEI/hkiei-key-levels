# Key Levels 支持位／阻力位

**v2.2.2 · 投創教育 HKIEI**

整理恒指、納指（納斯達克綜合指數）、標普 500 及道指的支持位、阻力位，以及最近一次回試或穿位時間，協助準備睇市功課。

## 下載

[下載 Key Levels v2.2.2](downloads/key-levels-v2.2.2.zip?raw=true)

解壓後請保留完整的 `key-levels` 資料夾，並先閱讀當中的 [安裝說明](key-levels/README.txt)。不要只取出 `SKILL.md` 或刪除程式及素材。

## 報告內容

- 四個現貨指數的支持位、阻力位及價位區間。
- 清楚標示觀察週期、行情日期及報價時間。
- 價區形成紀錄，以及最近一次回試或穿位時間。
- 可離線閱讀的 HTML 報告、價位圖表及 HKIEI 品牌樣式。
- 預設按已收市日線製作本週觀察報告，亦可要求五分鐘圖追蹤。

## 使用環境

需要 Mac、Python 3.9 或以上及互聯網連線。分析程式使用 Python 標準庫，毋須額外安裝 Python 套件。PNG 報告卡轉換使用 macOS 的 `sips` 或 AppKit。

ChatGPT 用戶可使用已安裝的「Key Levels 支持阻力」。下載 ZIP 本身不會自行替帳戶安裝插件。

Claude 用戶可在能讀取本機檔案的環境，按 [安裝說明](key-levels/README.txt) 安裝完整資料夾。

**Windows 尚未經實機測試，現階段暫不推薦 Windows 用戶下載及使用。** 如自行嘗試，請自行評估相容性；團隊暫不保證其運作或提供相關技術支援。

## 使用例子

> 幫我睇恒指本週支持位同阻力位，列出最近一次回試或穿位嘅時間。

> 分析恒指、納指、標普同道指嘅支持阻力，分別提供報告。

> 幫我追蹤恒指五分鐘圖最近嘅回試或穿位。
