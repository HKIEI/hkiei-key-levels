# Key Levels_HKIEI｜支持位・阻力位分析

**投創教育 HKIEI 製作**

睇市前，先整理值得留意的價位。

**Key Levels_HKIEI 是一套供 AI 執行的支持阻力分析工具。** 配合具備所需執行功能的 ChatGPT 或 Claude，它會讀取市場走勢，整理恒指及美國三大指數的支持位、阻力位，列出價位形成依據，以及最近一次回試或穿位時間，再製作成容易閱讀的 HTML 圖表報告。

你可以用它準備睇市功課、比較現價與關鍵位的距離，以及跟進價格到位後的變化。安裝後，用中文提出要求即可，毋須每次自行輸入程式指令。

**[下載 Key Levels_HKIEI](downloads/Key%20Levels_HKIEI.zip?raw=true)**

> 第一次使用：確認裝置及 AI 平台 → 下載及安裝 → 輸入分析要求 → 開啟報告。下載 ZIP 並不等於已完成安裝。

## 1. 這個 Skill 可以幫你做甚麼？

| 你想知道的事 | 報告會提供甚麼 |
| --- | --- |
| 現在要留意哪些位置？ | 最近的上方阻力、下方支持，以及其他符合條件的價位區間 |
| 為甚麼是這個位置？ | 形成價區的價格紀錄及日期，讓你了解其依據 |
| 這個位置最近有沒有反應？ | 形成後最近一次回試或穿位的時間及紀錄；尚未回試亦會寫明 |
| 現價與這些位置有多遠？ | 圖上對照參考價與支持阻力區，並標示資料時間 |
| 我應該看哪段時間？ | 列明觀察週、選位所用走勢及更新日期，區分日線與五分鐘圖 |

**主要交付：一份可用瀏覽器開啟、下載後可離線閱讀的 HTML 報告。** 報告包含價位摘要、圖表、形成與回試紀錄，以及資料限制。

支持位是用來觀察價格接近後是否反彈的區域；阻力位是用來觀察價格接近後是否回落的區域。兩者都是觀察位置，並不保證價格到位後一定按預期方向走。

## 2. 適用市場

**本 Skill 的主要使用範圍是以下四個現貨指數：**

| 市場 | 可直接輸入的名稱 | 實際分析對象 |
| --- | --- | --- |
| 香港 | 恒指 | 恒生指數現貨 |
| 美國 | 納指 | 納斯達克綜合指數（Nasdaq Composite） |
| 美國 | 標普／標普 500 | 標準普爾 500 指數 |
| 美國 | 道指 | 道瓊斯工業平均指數 |

**這裏的納指是納斯達克綜合指數，並非 Nasdaq 100。** 現貨指數的點數亦不可直接當作期貨、ETF 或其他產品的買賣價。

可只分析一個指數，亦可一次要求分析「恒指及美國三大指數」。

| 分析方式 | 適合甚麼用途 | 如何提出要求 |
| --- | --- | --- |
| 日線選位、本週觀察 | 整理本週值得留意的支持阻力 | 「幫我睇恒指本週支持位同阻力位」 |
| 五分鐘圖追蹤 | 查看較短時間內的回試及穿位紀錄 | 明確加上「五分鐘圖」 |

「本週」是報告的觀察期間，選位依據預設為已收市日線，並不等於使用週線選位。五分鐘圖可取得的範圍及完整程度，取決於走勢來源。

## 4. 安裝方法

### 第一步：下載正確檔案

1. 按 **[下載 Key Levels_HKIEI](downloads/Key%20Levels_HKIEI.zip?raw=true)**，儲存 `Key Levels_HKIEI.zip`。
2. 按你使用的平台，跟隨下面 A 或 B 的安裝方式。
3. 如遇到 404 或無法下載，先確認已登入有權限存取本儲存庫的 GitHub 帳戶。

> 請使用上方的 Skill ZIP。GitHub「Code → Download ZIP」下載的是整個儲存庫，不能把它直接當作同一個 Skill 安裝包。

### A. ChatGPT 用戶

**如果已安裝「Key Levels_HKIEI」：** 直接開新對話，選取該外掛並使用第 5 節的指令，毋須重複安裝。

**如果帳戶提供 Skills 上載功能：**

1. 在 ChatGPT 側邊欄開啟 **Plugins（外掛）**，再選 **Skills**。
2. 選 **Create → Upload from your computer**。
3. 選取下載的 `Key Levels_HKIEI.zip`，按畫面指示完成掃描及安裝；不要只上載 `SKILL.md`。
4. 確認 Skills 清單出現 **Key Levels_HKIEI**，再開新對話測試。部分介面會顯示技術識別 `key-levels`。

介面及上載權限以帳戶實際提供的功能為準；沒有 Skills 或上載選項時，請查閱 [ChatGPT 官方 Skills 說明](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)。把 ZIP 放入一般對話作附件，不等於已永久安裝 Skill。

**安裝後還要確認執行能力：** 若 ChatGPT 表示無法執行 Python、讀取套件或連線取得走勢，該次對話便未具備完整運行條件；單純安裝成功不代表已能產生報告。

### B. Claude 本機用戶

以下步驟適用於 **Mac 上的 Claude Code**，不是把檔案貼入一般 Claude 對話。

1. 雙擊 ZIP 解壓，取得完整的 `Key Levels_HKIEI` 資料夾。
2. 將資料夾放在 Mac 的「下載」資料夾；如放在其他位置，請在下方指令改成實際位置。
3. 開啟 Claude Code，貼上以下指令：


4. 如出現檔案讀寫或執行許可，核對內容後按平台提示處理。
5. 安裝完成後開啟新對話，輸入「請使用 Key Levels_HKIEI 分析恒指支持阻力」。如要用斜線指令，可輸入 `/key-levels`。

## 5. 使用方法

安裝後，按需要直接複製以下其中一條指令。

### 查看恒指本週關鍵位

```text
幫我睇恒指本週支持位同阻力位，列出最近一次回試或穿位嘅時間。
請標明完整觀察日期、資料截至時間，並提供 HTML 圖表報告。
```

### 一次查看四個指數

```text
用 Key Levels_HKIEI 分析恒指、納指、標普同道指本週支持阻力。
每個指數分開列出價位、資料日期，以及最近一次回試或穿位時間。
請提供 HTML 報告。
```

### 查看五分鐘圖紀錄

```text
幫我追蹤恒指五分鐘圖嘅支持位同阻力位，列出最近一次回試或穿位時間。
請標明可取得嘅走勢期間同最新資料時間，並提供 HTML 報告。
```

### 更新已有報告

```text
請重新取得最新可用走勢，更新恒指嘅支持阻力報告。
保留原有報告，另存新檔，並列明今次更新嘅資料時間。
```

### 報告生成後，怎樣看？

1. **下載 `.html` 檔案**，在 Mac 用 Safari 或 Chrome 開啟。若對話內預覽沒有顯示圖表，先下載後再開啟。
2. **先看日期及週期**：確認是哪個市場、哪一週、日線還是五分鐘圖，以及資料截至何時。
3. **再看最近的支持及阻力**：價位通常是一段區間，應看清上下邊界；如有其他價區，可繼續向下閱讀或展開。
4. **最後看回試及穿位紀錄**：了解價格曾從哪邊接近、當時怎樣反應，以及記錄日期。

報告下載後可離線閱讀，但內容不會自行更新。需要新走勢時，請再次執行分析。

## 6. 使用前請留意

- **資料來源：** Yahoo Finance 公開走勢，可能有延遲、缺漏、連線限制或修訂；請以報告標示的日期及時間為準。
- **週期及時區：** 日線與五分鐘圖的用途不同；港股與美股亦有時差，請連同報告時區閱讀事件時間。
- **更新方式：** 每次執行才取得當時可用資料；本套件本身不提供全天候監察、即時推送或自動落盤。
- **價位判讀：** 支持及阻力是觀察區，並非保證反彈或回落的位置。沒有符合條件的價區時，報告會如實說明。
- **檔案完整性：** 請保留整個 `Key Levels_HKIEI` 資料夾及 `assets`，不要只保留 `SKILL.md` 或刪除個別程式。
- **平台費用：** 使用 ChatGPT、Claude 或其他服務所需的帳戶資格、訂閱及用量費用，按各平台規定處理。

**Windows 使用說明：** 本 Skill 尚未經 Windows 實機測試，現階段暫不推薦 Windows 用戶下載及使用。如仍希望自行嘗試，請先評估裝置相容性並備份相關資料。團隊暫不保證 Windows 環境下的功能完整性或運作穩定性，亦未能提供相應技術支援；因自行安裝或使用而產生的問題，須由使用者自行評估及處理。

**A.I. 生成聲明：** 報告及重要價位由 A.I. 根據公開走勢自動計算及生成，未經人工逐一核實，或有錯誤或延遲。

**免責聲明：** 本 Skill 及其輸出僅供教育及資訊參考，不構成投資建議、要約或招攬買賣證券。支持位及阻力位是根據過往價格計算的觀察位置，不代表價格必定反彈或回落。投資涉及風險，過往表現不代表將來表現。使用者應自行核實資料並作獨立判斷。

## 7. FAQ｜常見問題

<details>
<summary><strong>我不懂寫程式，可以使用嗎？</strong></summary>

可以按本指南安裝，再用中文提出分析要求，日常使用毋須自行編寫程式。首次設定仍需要具備執行能力的 AI 平台，以及合適的 Python 和網絡環境。

</details>

<details>
<summary><strong>只可以看本週？可不可以看五分鐘圖？</strong></summary>

預設用已收市日線整理本週觀察位；你亦可明確要求五分鐘圖追蹤。「本週」是觀察期間，不是唯一支援的圖表週期。五分鐘走勢不足時，報告須標示限制，不能補作紀錄。

</details>

<details>
<summary><strong>可以分析個股、期貨或其他市場嗎？</strong></summary>

本指南及主要指數追蹤流程以恒指、納指綜合、標普 500、道指現貨為範圍。套件另有一般證券分析程式，但其他標的並非這套四指數流程的同等適用承諾；使用前應另行核對代號、交易時段及資料覆蓋。

</details>

<details>
<summary><strong>是不是即時報價？會一直自動追蹤嗎？</strong></summary>

不是即時走勢服務。每次執行會讀取當時可取得的資料，報價可能延遲；打開 HTML 亦不會持續更新。要更新紀錄，請重新執行分析。

</details>

<details>
<summary><strong>為甚麼報告寫「暫未確認支持位」或「尚未回試」？</strong></summary>

「暫未確認」表示目前可用資料中，沒有找到符合條件的該方向價區，不代表市場永遠沒有支持或阻力。「尚未回試」則表示價區形成後，現有紀錄未見符合條件的回試。兩者不可當作買賣訊號。

</details>

<details>
<summary><strong>到支持位就可以買、到阻力位就要賣嗎？有保證準確率嗎？</strong></summary>

價位用來觀察反應，不是自動買賣指示，也沒有保證準確率。過往回試紀錄不等於下一次的成功機率，應連同最新價格變化及個人風險承受能力判斷。

</details>

<details>
<summary><strong>為甚麼 ZIP 內有這麼多檔案？可以只留 SKILL.md 嗎？</strong></summary>

安裝包共有 22 個檔案：2 份指引、12 個 Python 程式、7 個報告素材及 1 份顯示名稱設定。它們分別處理走勢、價位、追蹤紀錄及報告外觀，互有依賴。請保留完整資料夾；只留下 `SKILL.md` 會缺少實際執行所需的程式與素材。

</details>

<details>
<summary><strong>安裝了，但 AI 說不能執行，或者一直沒有走勢，怎麼辦？</strong></summary>

先請 AI 檢查套件路徑、Python 版本、檔案讀寫權限及網絡連線。找不到程式時，確認完整資料夾沒有缺檔或多套一層。若出現 403、429 或連線逾時，可能是走勢來源限制，可稍後再試；不可把舊資料或估算價位當作最新結果。

</details>

<details>
<summary><strong>HTML 報告開不到或只看到程式碼，怎麼辦？</strong></summary>

先把 `.html` 檔案下載到 Mac，再在 Finder 對檔案按右鍵，選「打開檔案的應用程式」→ Safari 或 Chrome。不要用文字編輯器閱讀，也不要把檔名改為 `.txt`。下載後可離線開啟，但仍只反映生成時的資料。

</details>

<details>
<summary><strong>README 是甚麼？下載後怎樣閱讀？</strong></summary>

README 就是安裝及使用說明。你現在看到的 GitHub 首頁會自動排版顯示 `README.md`，毋須另裝閱讀軟件。ZIP 內的 `README.txt` 是簡短說明，可在 Mac 雙擊，以「文字編輯」開啟。

</details>

<details>
<summary><strong>GitHub 顯示 404，或朋友打不開下載連結？</strong></summary>

如果儲存庫是 Private，只有獲授權的 GitHub 帳戶可閱讀及下載，分享網址本身不會授予權限。請確認已登入正確帳戶；未獲授權人士須由提供者另行安排下載或存取方式。

</details>

<details>
