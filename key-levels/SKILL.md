# Key Levels_HKIEI（支持位／阻力位）

以 Yahoo Finance 日線劃出收市時可知的支持及阻力，並以五分鐘圖走勢量度首次觸及後的反應。腳本使用 Python 3.9+ 標準庫，預設輸出可離線閱讀的 HTML、股價圖及報告卡。

## 恒指及美國三大指數的支持位及阻力位

用戶問恒指、道指、標普 500 或納斯達克綜合指數的本週關鍵位，或只問這些指數的支持阻力而未指定周期，執行 `track_indices.py --weekly`。指定週或下週時傳入 `--week-of YYYY-MM-DD`。只選用戶點名的指數。明確要求即市、五分鐘或逐項歷史追蹤時，使用不帶週報參數的詳細追蹤模式。以同一次命令處理多個指數。

週報直接使用週報輸出。首頁寫出當地交易週的起訖日期、周初所用的最後一個收市、此次更新的收市與適用日期。選位用已收市日線（一個交易日一支），每次收市後按仍然有效的價區更新。資料只足以作提前預覽或事後回顧時要如實標示。某個方向沒有符合條件的價區便照實寫明。前高、前低、前收或即市反應只可在另行要求的走勢參考中列出，不能自行補作週報關鍵位。最近一個先列，其餘符合條件的區可展開；價格距離只決定閱讀次序。對每區說明價格從哪一側接近、已有甚麼證據，以及形成後最近的回試或穿位，尚未回試也要寫清楚。

週報排版先讓讀者看見最近的上方阻力、下方支持與收市價。觀察週、資料截至哪天及本版適用日期用短行分開。主要價區用大字，附一句到價後觀察甚麼，接着列最近回試或穿位。把形成價區的兩筆價格紀錄並排對照，較遠價區及計算說明留給讀者展開。手機版將主要價區排成單欄。保留完整數值和可離線閱讀的內容。 週報頁首在白底展示一次投創教育中英文標誌，內嵌圖片以供離線閱讀。沿用 HKIEI 的深藍、靛藍和青綠配色，以深色顯示文字、青綠標示分隔。標題用明體，內文及價位用黑體。手機、電腦及列印版各自沿用大字字級，拉開行距、日期與價位、解讀與最近紀錄之間的距離。較遠價區各自成組，寬屏及列印可並排，手機上下排列。

週報首頁的日線陰陽燭圖直接以日期範圍起首，顯示最近最多 30 個已收市交易日，同圖按實際點數畫出全部已確認價區，從目前範圍確認或更新之日開始。盤中用獨立菱形標示附來源、當地時間的報價，保留選位所用的收市價。沒有同日可核對的時段報價，或查看其他交易週時，在最後一支燭標示該日收市。某一側尚未確認便在圖旁說明。列印時第一頁看陰陽燭與主要價區，形成及回試紀錄另頁展示。

若目前只有已保存的日線，可用同一現貨指數經核對的盤中報價補充圖中位置。合併快照保留原有 Yahoo 日線及交易日，`keyLevelsCapturedAt` 記錄整份快照整理時間（Unix 秒）。可選的 `keyLevelsIndexQuote` 包含 `symbol`、`value`、附時區的 ISO 時間 `at`、`source` 和 HTTPS `url`。只選用快照當日、報告週內及交易時段內的報價。盤中位置不參與選位及日線回試判定。

自然語言例子：「幫我追蹤恒指同美國三大指數嘅支持位同阻力位，列出最近一次回試或穿位嘅時間。」

- 指令、示例、標題、圖表、檔名、對外回覆和匯出只用一般價位用語。只列價格、日期、資料來源、形成依據及回試或穿位紀錄；不要自行補充策略編號或教學來源對照。額外選取的走勢參考須指出實際來源，不能按價位接近便追認分類。
- 詳細追蹤模式分日線及五分鐘列示，按支持位、阻力位排列。方向尚待收市確認的區間獨立列出。報告列參考指數、價位範圍、形成時間、最近錄得的回試、穿位及收回。可用當時的高低位、開收市價和時間解釋價格經過。區分暫無有效價位、走勢不足及日線待收市。
- 從文字、HTML 或對外 JSON 讀取結果。JSON 在 `daily.levels` 及 `intraday.levels` 內按 `support`、`resistance`、`range` 提供追蹤中及已結束紀錄。`id` 可跨次查詢識別同一價位。
- 重跑時按已完成走勢更新。用戶明確要求歷史成績時才使用下方回測流程。其他證券沿用一般支持阻力分析。

## 一般證券分析及明確要求的回測

先找出本 `SKILL.md` 所在的資料夾，再以腳本的絕對路徑執行（不要假設工作目錄就是 skill 資料夾）：

```bash
python3 "<skill 資料夾>/key_levels.py" '^HSI' --size 1080x1920 --svg ./hsi.svg --html ./hsi_report.html --card ./hsi_card.png
python3 "<skill 資料夾>/key_levels.py" 0700.HK --size 1920x1080 --svg ./tencent.svg --card ./tencent_card.png --json ./tencent.json
python3 "<skill 資料夾>/key_levels.py" NVDA --reaction-days 30 --svg ./nvda.svg --card ./nvda_card.png
```

- **每次分析預設交付 HTML 報告**：腳本自動輸出與 SVG 同名的 `.html`；可用 `--html <檔名>.html` 指定位置。執行後核對檔案存在，再以可點擊連結交付，不能只說「已生成」。只有用戶明確不需要 HTML，或純機器批次處理時，才用 `--no-html`。
- HTML 為單一可離線開啟的檔案，內嵌品牌圖像、樣式、腳本及數據；毋須 CDN、伺服器或額外套件。包含摘要、互動股價圖、支持阻力表、其他參考線、閱讀說明、資料限制及聲明。可切換圖表日數、切換價位色帶、點按／移動游標或以方向鍵查看每日價格，亦可列印。
- **預設必須加 `--card <檔名>.png`**，輸出 1080x1350 投創教育品牌報告卡，供用戶自行保存或分享。macOS 先使用內置 `sips`，需要時自動改用 AppKit。兩者均未能轉換時改用 `.svg` 檔名。
- 代號：港股為四位數字加 `.HK`（`0700.HK`；輸入 `09988.HK` 會自動改為 `9988.HK`），恒指 `^HSI`，國企指數 `^HSCE`，納指 `^IXIC`，標普 `^GSPC`，美股直接輸入代號，加密貨幣 `BTC-USD`。「恒指」、「納指」可直接輸入中文。
- 需要兩個尺寸時，第一次加 `--save-raw ./raw.json`，第二次用 `--input-json ./raw.json`。快照保留擷取時間及補取的較早走勢。重播盤中快照時，按原本的交易時段狀態評分。
- 其他參數：`--json`（標準輸出只含 JSON；圖表及 HTML 檔仍會生成）、`--lookback`（預設 120 個交易日）、`--psych-step`（心理關口間距，恒指預設 500 點）、`--merge-pct`、`--merge-atr`（預設 0.3）、`--min-gap-atr`（預設 0.5）、`--chart-days`（HTML 初始顯示日數，不改變統計回看期）、`--overwrite`（須經用戶確認方可使用）。
- HTML 股價圖顯示最新參考價附近的位置。「支持反彈與阻力回落」另外列出上日收市固定的兩層支持及阻力，以及每邊當日開市選用的位置。
- 每次預設附上最近 30 個已收市交易日的逐日回測。以 `--reaction-days N` 指定 1 至 252 日。連網時會補取較早走勢作預熱。若禁用延長歷史或使用舊離線快照，按實際可重建日數及觸及次數列示。
- 若 Python 無法連線，可用可取得同一 Yahoo Chart API 的環境讀取三個原始回應。以 `/v8/finance/chart/<代號>?range=1y&interval=1d` 作主檔，用 `range=5y&interval=1d` 補充預熱，並以 `period1=<起點 Unix 秒>&period2=<擷取 Unix 秒>&interval=5m&includePrePost=false` 取得最多最近 59 個曆日的五分鐘圖走勢。主檔保留原有 `chart`，加入 `keyLevelsEarlierChart`、`keyLevelsIntradayChart`（各自完整回應）及主檔的實際擷取時間 `keyLevelsCapturedAt`，用 `--input-json` 重播。亦可透過 `--intraday-json <檔案>` 指定五分鐘原檔。舊快照只有日線時，列出可核對的收市結果及一小時樣本數。
- 腳本不會覆寫已存在的檔案。如出錯（沒有數據、網絡問題、HTTP 429／403），須如實報告，不可憑記憶估算價格。

## 向用戶報告（新手版，書面語）

全份報告使用書面語及香港投資用語（例如支持位、阻力位、心理關口、上日收市價、前期高位、日線），不用廣東話口語。依照腳本文字報告的次序及用詞，不要改回術語版：

1. **摘要**：現價、最近的阻力位及支持位（價位區間、與現價距離 %）；註明報價時間及「可能有延遲」。照列腳本摘要下的背景句（平均日波幅、位置密集、未填補裂口）。
   **支持反彈、阻力回落**　列明劃位日、觀察日及開市選層。先報首次觸及後一小時的方向，再列全日穿越區間遠端及收市反應。分開列出第一層、僅在開市啟用的後備第二層及兩層合計，各列分子和分母。評估 75% 等目標時，指明指標、期間、可評觸及及走勢覆蓋。
2. **阻力位表、支持位表**：使用「阻力 1／2／3」、「支持 1／2／3」，欄位為價位區間、距離現價、過往反應次數、過往觸及次數、形成原因。不足 3 個須如實說明，不可虛構補足。另列現價所處區間，以及 ⭐ 標示的區間（照腳本字眼：股票為「表內反應次數及成交量綜合最高的區間」，指數為「表內反應次數最多的區間」）。
3. **其他參考線**：只列上日高位、低位、收市價及 52 週高位、低位，分「現價之上」、「現價之下」兩組，由近至遠排列。不要在此列出移動平均線；日線只會在構成支持或阻力時出現在表內。
4. **名詞解釋**、**使用提醒**：照腳本輸出（「日線」及「支持阻力互換」兩項只在相關時出現）。
5. **HTML 報告、股價圖及報告卡**：優先連結 HTML 可視化報告，再展示或連結 SVG 股價圖及 PNG 報告卡。稱為「股價圖」、「報告卡」，不要稱為「K 線圖」。HTML 及報告卡均有「A.I. 計算及生成」標示、A.I. 生成聲明及免責聲明，不可要求或協助移除。離線快照或合成數據須保留醒目標示，不可稱為最新走勢。
6. **資料限制**：保留腳本「⚠️ 資料限制」各項。「進階資料」可列一般價區的識別碼及統計評分。
7. **A.I. 生成聲明及免責聲明（每次必須附上，置於最後）**：
   > 🤖 本圖像及當中重要價位由 A.I. 根據 Yahoo Finance 公開數據自動計算及生成，未經人工逐一核實，或有錯誤或延遲。

   > ⚠️ 免責聲明：本內容僅供教育及資訊參考，並不構成任何投資建議、要約或招攬買賣任何證券。支持位／阻力位僅為根據過往價格計算的觀察位置，並不代表股價必定在該處反彈或回落。投資涉及風險，證券價格可升可跌，過往表現不代表將來表現。數據來自 Yahoo Finance 免費公開來源，可能有延遲或錯誤。投資者應自行判斷，如有需要請諮詢持牌專業人士。

## 嚴禁事項

- 只可列出有期間、條件、分子及分母的歷史比例。不得將其當成下一次的成功機率，亦不可保證到位必定反彈或回落，或給予買賣指示。
- 不可將過往反應次數、觸及次數或統計評分說成守穩的機率。
- 不可將日線結果當作即市訊號。

## 逐日回試的評分方式

- 上日收市用當時已知走勢和 14 日 ATR，凍結最近兩層支持及阻力。每邊獨立決定。支持只在開市價嚴格高於區頂時合資格，阻力只在開市價嚴格低於區底時合資格。第一層已在區內、邊界或區間另一側時，才檢查第二層。兩層均不合資格便略過該方向。只有第一層存在才檢查後備。開市後全日固定該邊選擇，第一層盤中失守亦不換位。
- 一小時以正常交易時段的五分鐘圖走勢、所選區間的首次觸及為準，從下一支燭的開市價觀察十二支完整連續燭。支持向上與阻力向下為順向。先走到正、負半個上日 ATR 的一邊決定結果。每支燭先看開市價，若高低位均到門檻且先後無法判定，記「同燭先後不明」。一小時兩邊均未到記「兩邊未到」。兩者均計入可評觸及分母。
- 每日每邊只評一次。五分鐘首支燭與日線開市須同樣在合資格方向。首觸前跳過整區、全日走勢缺漏、午休或收市前不足連續一小時、零 ATR、未見觸及均另列。港美現貨股票及指數使用可核對的連續交易時段，港股午休及收市競價不接續計時。已識別的 UTC 全日加密貨幣亦可評估，其他未核實時段保留日線成績。
- 日線另列觸及、收回原側、收市順向拉開至少半個上日 ATR、日內穿越遠端及收市仍穿位。支持跌穿以低位嚴格低於區底計，阻力升穿以高位嚴格高於區頂計。原第一層全部／區外／¼ ATR 舊指標保留作對照。
- 按事前波幅分組時，以上日 ATR 佔收市價的百分比對照此前 60 日中位數，兩組均入總成績。比較規則須列出保留機會的比例。
- JSON 的 `reaction_watch` 保留逐日劃位及開市選層，`hourly` 列出一小時結果、覆蓋及排除原因，`layer_scores` 列出收市反應。2026-11-20 定稿後的新交易日獨立呈列，按當次回看區間計算。盤中只列已知開市及觸及狀態，收市後才評分。以修訂後走勢重建與有時間戳的實際發出紀錄應分開說明。

## 恒指現貨的歷史反彈、回落評分（明確要求回測時）

- 用恒指現貨，以當日開市前可取得的走勢選位。每個交易日及方向只計一次。對外按支持、阻力及合計顯示，保留舊版價區對照。
- 按原有規則記錄首次觸及後的收市反應、失守、未決、順向半個 ATR、觀望日及資料覆蓋。內部演算法與門檻保留在程式及維護參考內。零分母列「無可評樣本」，並分清歷史重建與實際事前發布。

## 計算方法（用戶查詢時才詳細說明）

| 項目 | 做法 |
|---|---|
| 現價 | Yahoo `regularMarketPrice`，可能延遲，不包括盤前及盤後交易；如欠缺則採用最新交易日收市價（只顯示日期）。報價時間與本機時鐘相差 3 小時內仍採用，並提示檢查電腦時間 |
| 上日高位、低位、收市價 | 報價日之前最近一個已收市交易日 |
| 前期波段高低位 | 左右各 3 個已收市交易日確認（`--swing-window`） |
| 日線 | 20／50／250 天指數移動平均線（EMA）；`--ma sma` 可改用簡單移動平均線 |
| 52 週高低位 | 最新已收市交易日往前 364 日的最高及最低價 |
| 心理關口 | 恒指每 500 點；其他標的按現價約 4% 選取 1／2.5／5／10 的間距（例：109 → 5，600 → 25） |
| 平均日波幅（ATR） | 近 14 個已收市交易日真實波幅（計及裂口）的簡單平均 |
| 裂口 | 回看期內相鄰兩日之間尚未被填補的空白價位（至少 0.3 個 ATR），上沿及下沿均列作候選；最多取最近 3 個 |
| 成交密集區 | 將每日成交量平均分配至當日最高與最低價之間的估算；指數預設不使用成交量 |
| 合併 | 相距不超過「現價 0.25%」與「0.3 個 ATR」兩者較大者的候選價位合併為一個區間 |
| 過往觸及次數 | 過去 120 個交易日股價觸及該區間的次數，連續多日只計一次 |
| 過往反應次數 | 觸及後股價從原來方向離開，並在 5 個交易日內收市拉開至少 0.5 個 ATR 的次數；穿越而過不計 |

| 入表間距 | 同一方向的位置之間最少相隔 0.5 個 ATR；太近時保留評分較高者 |
