Key Levels 支持位／阻力位 v2.2.2
投創教育 HKIEI

用途
整理恒指、納指（納斯達克綜合指數）、標普 500 及道指的支持位、阻力位，以及最近一次回試或穿位時間。
預設按已收市日線製作列明日期的本週觀察報告；亦可要求五分鐘圖追蹤。
輸出可離線閱讀的 HTML 報告，包含價區、圖表、形成紀錄、資料時間及免責聲明。

所需環境
- Mac 電腦、Python 3.9 或以上及互聯網連線。
- 分析程式使用 Python 標準庫。PNG 報告卡轉換使用 macOS 的 sips 或 AppKit。
- 首次使用時如 Mac 提示安裝「指令列開發者工具」，請完成安裝後再試。
- Windows 尚未經實機測試，現階段暫不推薦 Windows 用戶下載及使用。如自行嘗試，請自行評估相容性；團隊暫不保證其運作或提供相關技術支援。

使用例子
- 幫我睇恒指本週支持位同阻力位，列出最近一次回試或穿位嘅時間。
- 分析恒指、納指、標普同道指嘅支持阻力，分別提供報告。
- 幫我追蹤恒指五分鐘圖最近嘅回試或穿位。

檔案說明
- SKILL.md：讓 AI 知道何時及如何執行分析。
- README.txt：本安裝及使用說明。
- 12 個 Python 程式：行情處理、價區計算、事件追蹤、歷史統計及報告輸出，彼此有相依關係。
- assets 內 7 個檔案：報告樣式、圖表互動、圖片轉換及 HKIEI 標誌。
請保留整個資料夾，不要只取出 SKILL.md；亦不要刪除 assets 或個別 Python 程式。
